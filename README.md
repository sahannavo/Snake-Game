# Snake Game

A classic Snake game built with Python and Pygame.

## How to Play

- Use arrow keys to control the snake
- Eat the red food to grow and increase your score
- Avoid hitting the walls or yourself
- Press ESC to quit (close window)

## Requirements

- Python 3.x
- Pygame

## Installation

```bash
pip install pygame
```

## Running the Game

```bash
python main.py
```

## Controls

- ↑ UP
- ↓ DOWN
- ← LEFT
- → RIGHT
